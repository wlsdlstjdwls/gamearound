### 1. psstore (`1d9da39`)

같은 날 오전에 껐다가(`259374a`) 되살렸다. **끈 판단이 틀렸다** — 근거였던 "카탈로그는 이미 찼다"는
행 수를 센 것이고, 그 행의 값은 비어 있었다. 되살리며 실행처를 Actions 에서 서울 크론으로 옮겼다:

```
/api/cron/crawl/psstore/prices    45 */6 * * *    하루 4회 × 300건 = 1,200건/일
/api/cron/crawl/psstore/discover  30 4,16 * * *   하루 2회 × 120건
```

Actions 자리는 하루 2회 × 200건이 한계였다(한 바퀴 108일). 크론은 1회 800초라 300건이 든다.
**두 곳에서 같이 돌리지 않는다** — Redis 락에 걸려 한쪽이 빈손으로 끝난다.

### A. 출시예정 축이 없다 — 이 회차 최대 발견

미래 출시일이 붙은 행이 **184행**, 90일 안은 80행뿐이다(steam 28, xbox 28, ps5 24).
**화면도 없다** — `lib/routes.ts` 에 출시예정 경로가 없다.

어댑터 다섯 곳 다 `releaseDate` 를 파싱한다. 안 채워진 이유는 상세 조회를 못 받은 행이라서다.
psstore 재개로 하루 1,200건씩 채워지기 시작하지만, 그것만 기다리면 느리다. 값싼 순서:

1. **스토어의 "출시예정" 목록을 직접 긁는다.** PS, eShop, Epic, Steam 다 그 목록이 따로 있다.
   카탈로그 전체를 훑지 않고 미출시작만 집으므로 제일 싸다. 어댑터에 `discoverUpcoming` 을 더하고
   `sync/discover` 는 건드리지 않는 모양이 맞다(AGENTS §5).
2. **게임 단위 폴백.** 스팀이 아는 날짜를 같은 게임의 다른 스토어 행에 보여 준다. 멀티플랫폼 3,429건이
   즉시 해결된다. 서비스 계층(`services/games`)에서 끝나는 일이라 수집을 안 건드린다.
3. 위키데이터 P577. 이미 `wikidata_game` 어댑터가 있다.

### B. 일본 전용 게임을 검색에 넣을지 결정

JP 전용 본편 360건은 지금 **목록에도 검색에도 안 나온다**. 목록 질의가 `region=KR` 행만 집계하고
그 행이 없는 게임은 `innerJoin` 에서 빠지기 때문이다(`services/games/list.ts`).
사용자는 "목록에는 필요 없고 검색은 되면 좋겠다" 고 했다 — 하려면 `q` 가 있을 때만
`agg` 를 left join 으로 돌리고, 원화 없는 게임을 항상 뒤로 세운다(`hasBaseCurrency` 가 이미 있다).
JP 전용 360건 중 230건은 제목이 일본어라 별칭 없이는 한국어로 검색해도 안 걸린다는 점도 같이 본다.

## 다음 회차가 먼저 재야 할 숫자

이번에 바꾼 몫이 실제로 도는지는 하루가 지나야 보인다. 이 질의로 확인한다.

```sql
-- 1) psstore 가 실제로 도는가, 출시일이 차고 있는가
select platform, count(*) n,
  count(*) filter (where release_date is not null) dated,
  count(*) filter (where last_synced_at > now() - interval '24 hours') h24
from game_platforms where platform in ('ps4','ps5') group by 1;

-- 2) match 모드가 붙인 새 매핑
select source, matched_by, count(*) from game_source_refs
where checked_at > now() - interval '24 hours' group by 1,2;

-- 3) 메타 결손이 줄고 있는가
select count(*) filter (where title_ko is null) no_ko,
  count(*) filter (where description is null) no_desc,
  count(*) filter (where developer is null) no_dev
from games where content_type='game';
```

본편 no_ko 11,921 / no_desc 10,704 / no_dev 10,677.
