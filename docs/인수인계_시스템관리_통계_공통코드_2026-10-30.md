## 2. 동작 규칙(바꾸기 전에 알아야 할 것)

- **알림 발송은 전부 `server/notify/dispatch` 한 곳**을 지나 `notify_sends` 에 성공, 실패, 건너뜀과 사유를 남긴다.
  업무요청 넷(`task.*`)과 데이터 점검(`quality.run`)은 시스템 템플릿이다. 템플릿을 미사용으로 두면 그 알림이 멈춘다. 템플릿이 없으면 코드의 옛 글로 물러선다.
- 받는 곳은 공통코드 `NOTIFY_CHANNEL`(속성1 = 텔레그램 chat id). 비우면 환경 변수 `TELEGRAM_ADMIN_CHAT_ID`.
  사건 알림은 `TELEGRAM_BOT_TOKEN` 과 `TELEGRAM_ADMIN_CHAT_ID` 가 둘 다 있을 때만 보낸다(`telegramConfigured()`).
- **치환변수는 `{이름}` 하나**(띄어쓰기 없음). 요금 카드 문구 화면 꼴도 `{절약금액}`(저장은 `{saving}`). 대괄호를 새로 쓰지 않는다.
- **방문 기록**은 운영 배포(NODE_ENV, VERCEL_ENV 둘 다 production)에서만 센다. Redis 열쇠 `visits:`, `visitors:`(HyperLogLog), `visit-src:` + 한국 날짜, 400일.
  누가 봤는지는 남기지 않는다. 이용현황의 방문, 유입경로는 배포한 날부터 찬다.
- 매출 셈은 결제/환불관리 머리 숫자와 같다(결제는 승인일, 환불은 환불일).
- 공통 그리드(`screen/data-grid`) 몸통은 세로 스크롤을 가두지 않는다(가두면 그리드 위 휠로 화면이 안 내려간다). 긴 표는 `bodyMax`.
- 편집 화면의 행 이동 확인은 `components/admin/screen/row-leave.ts` 의 `confirmRowLeave`.

## 3. 공통코드 코드북

- 코드성 이름표(상태, 분류처럼 DB 값에 붙는 것) = `lib/codes/registry.ts` 의 기본값(기존 `*_LABEL`) 위에 공통코드관리에서 고친 값(DB)을 덮은 것(`lib/codes/book.ts`).
- 서버: `getCodeBook()`(캐시 태그 `common-codes`) + `codeName(book, 그룹, 코드)`. 클라이언트: `useCodes()`(`components/code-book.tsx`, 루트 레이아웃의 `CodeBookProvider`).
  저장 액션이 태그와 레이아웃을 밀어 바로 반영된다. DB 를 못 읽으면 기본값으로 선다.
- 등록 그룹은 코드값이 DB enum 이라 잠긴다(공통코드관리 구분 "시스템"). 고치는 것은 이름, 정렬순서, 사용여부. 미사용은 고르기 목록에서만 빠진다.

### 옮긴 그룹(끝)
업무 상태, 분류, 우선순위, 결제 상태, 구독 상태, 광고 자리, 광고 출처, 광고 노출 상태, 데이터 점검 규칙, 업그레이드 종류, 스토어 연결 방식, 수집 결과.

### 남은 일: 공개 화면 이름표

그룹을 `CODE_REGISTRY` 에 한 줄 더하고, 쓰는 자리를 `useCodes().name(...)` / `codeName(book, ...)` 으로 바꾼다. 기본 이름표 객체는 지우지 않는다.
모듈 수준 상수(그리드 칸 정의 등)에서 쓰던 것은 함수로 바꿔 `name` 을 받게 한다. 서버 화면은 `getCodeBook()` 을 다른 질의와 `Promise.all` 로 같이 읽는다.
`"use client"` 없는 공용 부품에서 훅을 쓰게 되면 클라이언트 부품으로 바꾼다(예: `components/promo/boost-state-tag.tsx`).

| 이름표 | 정의 | 쓰는 파일 수 |
|---|---|---|
| `CATEGORY_LABEL`(게시판 말머리) | `lib/community/constants.ts` | 8 |
| `PROMO_TYPE_LABEL`(홍보 유형) | `lib/community/constants.ts` | 4 |
| `PLATFORM_LABEL`, `platformLabel`(기종) | `lib/format.ts` | 26, 12 |
| `PLATFORM_FAMILY_LABEL`, `DEVICE_LABEL` | `lib/platform.ts` | 5, 6 |
| `COMPANY_ROLE_LABEL`, `CONTENT_KIND_LABEL`, `DECK_COMPAT_LABEL`, `OS_FAMILY_LABEL`, `REQUIREMENT_TIER_LABEL` | `lib/games/messages.ts` | 3, 2, 2, 9, 2 |
| `INDIE_STAGE_LABEL`, `INDIE_PLATFORM_LABEL`, `INDIE_GENRE_LABEL`, `INDIE_LINK_LABEL` | `lib/indie/messages.ts` | 7, 8, 3, 2 |
| `PATCH_KIND_LABEL` | `lib/patch-kind.ts` | 1 |

옮기지 않는 것: 정렬 이름, 검색 범위, 인기 기간, 테마처럼 데이터가 아니라 화면 문구인 것(`SORT_LABEL`, `*_SEARCH_SCOPE_LABEL`, `POPULAR_PERIOD_LABEL`, `THEME_LABEL`).
공개 화면은 ISR, 정적 화면이 많다 — 코드북 캐시 태그가 밀리면 다시 그려지는지(공통코드 저장 뒤 해당 화면 확인) 꼭 눌러 본다.

## 4. 확인하는 법

- 관리자 계정: `.env.local` 의 `CLAUDE_ADMIN_EMAIL` / `CLAUDE_ADMIN_PASSWORD`(다른 PC 는 PowerShell 에서 `vercel env pull` 로 받는다).
- 화면 몰기: `python scripts/admin-drive.py OUT.png /admin/<화면> [단계...]`(PowerShell 에서). dev 서버는 4000번.
- **로컬 DB 가 곧 운영이다.** 시험 값에는 `[테스트MMDD]` 표식을 붙이고 끝나면 지운다. 공통코드 시험 저장은 원래 이름으로 되돌린 뒤 그 그룹의 DB 줄을 지운다(등록 그룹은 줄이 없어도 기본값으로 선다).
- 이 PC 는 OS 환경 변수에 `TELEGRAM_BOT_TOKEN` 이 깔려 있다(다른 프로젝트용). 관리자 채널 chat id 가 없어 로컬 직접 발송은 "chat id 없음" 건너뜀으로 남는다. 실제 전송 확인은 배포 뒤.
- 빌드(`pnpm build`) 뒤에는 dev 서버를 다시 띄운다(`.next/dev` 지우고 `pnpm dev --port 4000`).
