## 1. 단계형 가입 (components/auth/sign-up-form/)

- `index.tsx` 폼, `steps.tsx` 단계 부품(SIGNUP_STEPS, StepHead, StepSlot, StepChip), `consent.tsx` 동의 넷.
- 단계: 닉네임, 이메일, 비밀번호, 비밀번호 확인, 약관. 지금 칸이 맨 위, 지나온 칸은 아래 칩(최근 순, `flex-col-reverse`). 칩을 누르면 그 칸으로, "다음" 은 가장 멀리 간 단계(reached)로 돌아온다.
- **input 은 한 벌**이고 단계는 CSS(`hidden lg:block`)로만 가린다. 넓은 화면(lg, 1024px~)은 옛 한 판 폼 그대로. matchMedia 로 두 벌을 그리지 않는 이유는 steps.tsx 머리말.
- "다음": zod 칸 검사만 기다리고, 중복 확인(remoteChecks)은 넘긴 뒤 뒤에서 묻는다. 걸리면 그 칸으로 되돌림. iOS 키보드 때문에 `flushSync` 후 같은 손짓 안에서 focus.
- `use-auth-form` 에 `validateField`, `checkRemote` 를 내보냈다.
- `lib/auth/schemas` 가입 스키마 refine 두 개에 `when`(cleanAt) — zod 4 는 객체 어딘가에 오류가 있으면 refine 을 건너뛰어 약관 전에는 "비밀번호가 서로 달라요" 가 안 섰다.
- 문구는 `lib/auth/messages` 의 signUpStepQuestions, signUpStepNotes, signUpNext, signUpEdit, signUpStepOf.

## 2. 모바일 점검에서 고친 것 (f191bc8)

회원 화면 47개를 390폭(일부 360)으로 캡처해 봤다. 가로 넘침은 0건.

- 머리띠 검색 자리글: 650 이하에서 "게임 검색"(`search-box.tsx` useSearchPlaceholder, useSyncExternalStore). 360폭 칸이 89px 뿐이다.
- 홈 히어로 검색, 인디 목록 검색, 게시판 글쓰기 관련 게임 칸 자리글 줄임.
- 히어로 설명 "한 화면에서", 멤버십 "(따로 사면 …)" 줄 없는 공백, 플레이타임 "메인 + 추가".
- 세일 일정 "시작까지" 를 좁은 화면에서 숫자 앞 한 줄로, 회사 국가 칩 이름과 숫자 사이 여백.
- 찜 목록 비었을 때 "0개 중 0개" 와 정렬 칩 숨김, 인디 등록현황 빈 판 "아직 등록한 게임이 없어요".

## 3. 새 버전 안내 (components/app-shell/update-notice.tsx)

- `next.config.ts` env `NEXT_PUBLIC_BUILD_ID` = VERCEL_DEPLOYMENT_ID 또는 VERCEL_GIT_COMMIT_SHA 또는 "local" (빌드 때 박힘).
- `/api/version`(force-dynamic, no-store)이 같은 규칙으로 실행 때 값을 준다. 다르면 바닥 띠 "새 버전이 나왔어요 [나중에] [새로고침]".
- 탭이 다시 보일 때(visibilitychange, focus) 묻고 1분(`lib/pwa` UPDATE_CHECK_INTERVAL_MS) 안이면 건너뜀. 로컬은 "local" 이라 안 뜬다.
- **아직 브라우저에서 띠가 뜨는 것은 못 봤다** — 운영 배포 두 번(배포 A 로 탭 열어 두고 배포 B) 뒤에 확인해야 한다.

## 4. 홈 화면에 추가 띠 (components/app-shell/install-banner.tsx)

- 650px 이하 + 홈, 찜, 가격 알림 화면만. 머리띠 위 흐름에 선다(site-header.tsx 맨 위).
- iOS 사파리: "추가" 를 누르면 두 걸음 안내(공유 단추, 홈 화면에 추가)를 띠 안에 편다. 안드로이드 크롬: beforeinstallprompt 를 잡아 설치 창.
- 이미 설치한 창(standalone), 설치 길 없는 브라우저는 안 뜬다. 닫으면 7일(localStorage `sjd_install_banner_dismissed_at`).
- iOS, standalone 판정은 `lib/pwa` 로 모았고 웹푸시 훅(push/use-push-subscription)도 같이 쓴다. 문구는 `lib/messages` INSTALL_MESSAGES, UPDATE_MESSAGES.

## 확인하는 법

- 모바일 캡처: `MSYS_NO_PATHCONV=1 PYTHONIOENCODING=utf-8 python scripts/mobile-shot.py 390 anon <폴더> / /games /sign-up`
  - 로그인 화면은 `auth` 모드. 저장소 루트 `.auth-state.json`(gitignore, playwright storage_state)이 필요하다. 없으면 admin-drive.py 의 계정(.env.local CLAUDE_ADMIN_*)으로 로그인해 `context.storage_state(path=".auth-state.json")` 로 만든다. 로그인을 반복하면 rl:auth 제한에 걸린다.
  - 출력 폴더의 `tiles/` 에 긴 캡처를 잘라 붙인 판이 생긴다.
- 가입 단계 확인은 제출하지 않고 "다음" 까지만 누른다(**로컬 DB 가 곧 운영**). 이번 회차에 만든 테스트 계정, 행은 없다.
