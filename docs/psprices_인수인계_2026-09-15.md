## 2. 모르면 헤매는 것

### Neon 드라이버가 백슬래시를 먹는다

**이게 제일 위험하다.** `@neondatabase/serverless` 로 보내는 SQL 문자열 리터럴 안의 백슬래시가
도착 전에 사라진다. 실측: `select length('\m') L, '\m' raw` 가 `L=1, raw='m'` 을 준다.

- 정규식 낱말 경계 `\m` `\M` `\y` 가 죽는다. `'\mdemo\M'` 이 `'mdemoM'` 으로 도착해 **0건을 잡는다.**
  에러가 안 나서 "해당 없음" 으로 보인다.
- `like '\_%'` 의 이스케이프가 죽는다. `_` 가 한 글자 와일드카드로 살아나 **전체가 걸린다.**

대신 쓸 것: 낱말 경계는 `(^|[^[:alnum:]])단어([^[:alnum:]]|$)`, 접두사 판정은 `left(name,1)='_'`,
문자 클래스는 `[[:digit:]]` 같은 POSIX 이름 클래스.

**기존 `_tmp-psprices-merge.ts` 의 EXCLUDE 정규식(`coins?\M`)도 이 때문에 깨져 있었다.**
아바타, 화폐 제외가 일부 안 먹었을 수 있다. 그 스크립트를 다시 돌릴 일이 있으면 먼저 고쳐라.

### 200페이지 벽

psprices 목록은 어떤 조건에서도 200페이지(7,200건)에서 잘린다. 201페이지부터는 200페이지
내용을 그대로 되돌려 준다(page=1000 과 page=2000 결과가 완전히 같다).
무필터로는 7,202건이 한계였다. price_min, price_max 로 구간을 재귀 이분하면 구간마다
새 창이 열려 73,897건까지 나온다. 구간 끝은 404 로 판정한다 — 건수 표기가 없어서 이게 유일한 종료 신호다.

### 차단은 경로가 아니라 지문을 본다

평범한 Chrome UA 를 붙인 curl 은 200 이다. headless 크로미움만 403 이다.
실제 Chrome 채널도 200 이다. 우리 createHttpClient transport curl 경로가 여기에 맞는다.

### SKU 가 유일한 교차언어 열쇠

우리 store_external_id 와 psprices sku 가 같은 형식이다.

    PS      우리 UP0102-CUSA00924_00-...   psprices UP1003-PPSA20560_00-...
    Xbox    우리 9NK9K07FDPJV              psprices 9n9gdw57cccq   (대소문자만 다름)
    스위치   우리 70010000133590            psprices 70010000017442

제목 유사도로는 교차언어를 못 잇는다. 우리 게임 중 한글 제목이 없는 게 7,951개인데
psprices 는 한글 제목으로 주는 게 17,472건이라 제목으로는 원리상 안 맞는다.
SKU 는 상세 페이지 ld+json 의 sku 에만 있다. 목록 카드에는 없다.

**주의**: PS 쪽 우리 `store_external_id` 는 콘셉트 id(숫자, 예 `10001183`)인 행과
전체 SKU 형식인 행이 섞여 있다. 숫자 콘셉트 id 행은 psprices sku 와 형식이 달라 안 맞는다.

### 플랫폼 기본 선택이 콘솔만이다

psprices 목록 기본값은 PS5, PS4, XOne, Switch, Switch2, iOS 다. 그래서 무필터로 훑으면
Meta Quest 가 통째로 안 보인다. platform=meta 로 붙으면 나오고 200페이지 상한에 닿는다
(최소 7,200건). 아직 안 가져왔다.
iOS 는 region-kr 에서 0건이고 region-us 에만 있다.

### 가격 이력만 난독화돼 있다

dynamics-data 가 JSON 을 표방하지만 자체 암호 문자열이다. 브라우저에서 복호돼 SVG 로 그려지므로
path 좌표와 축 눈금으로 역산해야 한다. HTTP 로는 못 읽는다.

## 3. 상세 수집 결과

`artifacts/psprices_detail.jsonl` 에 1,725건. `.done` 으로 재개 가능하게 돼 있다(지금은 다 찼다).

뽑은 값: sku, 표지, 이미지 12장, 설명, 출시일, 배급사, 용량, 플레이타임 3종, 자막, 오디오,
역대 최저가, 할인 종료일(priceValidUntil).

**이 파일의 `game_id` 를 오해하지 마라.** psprices 가 만든 신규 게임이 아니라
**검증 대상으로 고른 우리 기존 게임**이다. 1,725건 전부 우리 가격을 갖고 있다.
게다가 trigram 후보라 틀릴 수 있다 — sku 가 일치한 593건 중 36건은 다른 게임을 가리켰다.
**sku 가 가리키는 쪽이 사실이다.** psprices 가 만든 신규 게임은
`store_external_id = 'psprices:<ps_id>'` 인 행으로 찾아야 한다.
방향을 반대로 잡으면 조용히 0건이 나온다(실제로 한 번 나왔다).

### 검증 대상을 어떻게 좁혔나

기존 콘솔 게임 2,366개 중 제목으로 이미 psprices 와 이어진 1,061개는 위험이 없고,
남은 1,305개가 대상이었다. 로컬 trigram 으로 후보를 추려 1,725건.
`psprices_snapshot.name_norm` 컬럼과 `psprices_name_norm_trgm` GIN 인덱스는 그대로 남아 있다.
이게 없으면 유사도 조인이 전수 스캔이라 neon-http 타임아웃이 난다.

## 4. 중복 병합 결과 (12건이 정상이다)

`scripts/_tmp-psprices-dedup.ts` 로 처리했다. 12건은 적어 보이지만 실측한 깔때기가 설명한다.

1. 상세 sku 1,725건
2. 그중 우리 행과 sku 일치 **593건**
3. 그중 psprices 행이 DB 에 실제로 있는 것 **133건**
   (나머지 460건은 병합 때 가격이 충돌해 애초에 안 들어갔다. 이미 해결된 것들이다)
4. 그중 psprices 행이 다른 게임에 붙어 있는 것 **131건**
5. 그중 그 신규 게임이 psprices 전용인 것 **12건** — 이것만 옮길 수 있다

처리: 충돌 행 12건을 먼저 버리고(기존 값 보존), 남은 것을 옮기고, 빈 신규 게임 12개를 지웠다.
결과적으로 옮겨진 행은 0건이다 — 12건 전부 기존 게임이 이미 그 (platform, KR) 을 갖고 있었다.

### 남은 119건은 우리 카탈로그 자체 중복이다

4단계에서 5단계로 빠진 119건은 psprices 탓이 아니다. **같은 SKU 가 우리 게임 두 개에 걸려 있다**
(예: `Bus Simulator 27: Mercedes-Benz Intouro` 와 `Bus Simulator 27 - Mercedes-Benz Intouro`).
**전부 content_type='dlc' 다.** 본편 목록은 `content_type='game'` 만 보므로 화면에는 안 샌다.

합치려면 양쪽 다 우리가 수집한 가격이 붙어 있어 어느 쪽을 버릴지 판단이 필요하다. 손대지 않았다.
이어서 하려면 `docs` 의 이 항목과 `catalog-dedup` 기록을 같이 봐라.

## 7. 되돌리는 법

    delete from game_platforms where store_external_id like 'psprices:%';
    delete from games g where not exists (select 1 from game_platforms p where p.game_id = g.id);
    drop table psprices_snapshot;

psprices_snapshot 은 drizzle 스키마에 없다. 앱이 읽지 않는 외부 스냅샷이라 마이그레이션을
만들지 않았다. 스키마에 안 보인다고 없는 테이블이 아니다. 상세를 더 받거나 되돌릴 때
원본이 필요해서 일부러 남겼다.

데모 분류를 되돌리려면 `update games set content_type='game' where content_type='demo'`.
enum 값 자체는 되돌리지 마라 — postgres 는 enum 값 삭제를 지원하지 않는다.

## 9. 데이터 흠 두 가지

original_krw 없이 할인율만 있는 행이 있다. 카드에 취소선 정가가 없으면 배지 숫자를 그대로
쓰는 대비책이 걸린다. 정가 대비로 검증된 값만 쓰려면 original_krw is not null 을 붙여라.

korean 플래그가 실제보다 적다. 제목 괄호의 언어 목록에서 뽑는데 한글 제목인데 괄호가 없는
행은 false 로 떨어진다. 24,016건은 하한이다.
