## 2. 모르면 헤매는 것

### 200페이지 벽

psprices 목록은 어떤 조건에서도 200페이지(7,200건)에서 잘린다. 201페이지부터는 200페이지
내용을 그대로 되돌려 준다(page=1000 과 page=2000 결과가 완전히 같다).
무필터로는 7,202건이 한계였다. price_min, price_max 로 구간을 재귀 이분하면 구간마다
새 창이 열려 73,897건까지 나온다. 구간 끝은 404 로 판정한다 — 건수 표기가 없어서 이게 유일한 종료 신호다.

### 차단은 경로가 아니라 지문을 본다

평범한 Chrome UA 를 붙인 curl 은 200 이다. headless 크로미움만 403 이다.
실제 Chrome 채널도 200 이다. 우리 createHttpClient transport curl 경로가 여기에 맞는다.

### SKU 가 유일한 교차언어 열쇠

우리 store_external_id 와 psprices sku 가 같은 형식이다.

    PS      우리 UP0102-CUSA00924_00-...   psprices UP1003-PPSA20560_00-...
    Xbox    우리 9NK9K07FDPJV              psprices 9n9gdw57cccq   (대소문자만 다름)
    스위치   우리 70010000133590            psprices 70010000017442

제목 유사도로는 교차언어를 못 잇는다. 우리 게임 중 한글 제목이 없는 게 7,951개인데
psprices 는 한글 제목으로 주는 게 17,472건이라 제목으로는 원리상 안 맞는다.
SKU 는 상세 페이지 ld+json 의 sku 에만 있다. 목록 카드에는 없다.

### 플랫폼 기본 선택이 콘솔만이다

psprices 목록 기본값은 PS5, PS4, XOne, Switch, Switch2, iOS 다. 그래서 무필터로 훑으면
Meta Quest 가 통째로 안 보인다. platform=meta 로 붙으면 나오고 200페이지 상한에 닿는다
(최소 7,200건). 아직 안 가져왔다.
iOS 는 region-kr 에서 0건이고 region-us 에만 있다.

### 가격 이력만 난독화돼 있다

dynamics-data 가 JSON 을 표방하지만 자체 암호 문자열이다. 브라우저에서 복호돼 SVG 로 그려지므로
path 좌표와 축 눈금으로 역산해야 한다. HTTP 로는 못 읽는다.

## 4. 검증이 끝나면 할 일

### 4-1. 중복 병합

psprices_detail.jsonl 의 sku 를 우리 store_external_id 와 대소문자 무시로 맞춘다.
맞으면 그 psprices 행은 우리 기존 게임이다. 그때

1. 잘못 만들어진 신규 games 행에 붙은 game_platforms 를 기존 game 으로 옮긴다
2. 빈 신규 games 행을 지운다
3. 옮길 때도 (game_id, platform, region) 충돌이면 옮기지 말고 버린다 (기존 값 보존)

### 4-2. 데모 852건

체험판, Demo, Trial 이 content_type=game 으로 들어갔다. 목록에 본편인 척 섞인다.
content_type 을 바꾸든 지우든 정리해야 한다.

### 4-3. 그 다음 결정할 것

- 전체 68,968건 상세를 받아 이미지와 설명을 채울지 (약 10시간)
- Meta Quest 를 받을지 (platformEnum 에 값 추가 마이그레이션 필요)
- 안 가져온 축: 트로피, 장르, 동영상, 다른 지역 가격, 구독 포함, 에디션 관계

## 5. 커밋하지 못한 이유

최소 할인율 필터를 구현하고 검증까지 끝냈다.

- src/lib/games-query.ts  MIN_DISCOUNT_STEPS = [30, 50, 70], off 파라미터 파싱
- src/server/services/games/list.ts  maxDiscount >= off, 캐시 키 반영
- src/components/game-filters.tsx  할인 축을 칩 한 줄로 합침
- src/app/(public)/games/page.tsx  제목과 초기화 판정
- src/lib/games-query.test.ts  단 검증, 왕복 복원

typecheck, lint, test(607), build 전부 통과했고 로컬 4000번에서 실측했다
(전체 5,583 / 할인 중 2,599 / 30% 2,113 / 50% 1,673 / 70% 999).

그런데 커밋하지 않았다. 작업 도중 다른 곳에서 커밋 3개와 변경 60여 개가 들어왔고
내 변경이 그쪽 플랫폼 다중선택, 최대 가격 필터와 한 파일 안에서 엉켰다.
games-query.ts 에 내 MIN_DISCOUNT_STEPS 옆으로 MAX_PRICE_STEPS, parsePlatformValues 가 붙어 있고
game-filters.tsx 는 통째로 갈아엎어져 있다. 파일 단위로 내 것만 뗄 수가 없다.

이어받는 세션은 커밋 범위를 사용자에게 먼저 확인해라. 전부 한 덩어리로 담으면
AGENTS.md 9번(한 커밋은 한 가지 변경)을 깨고 검증 안 된 남의 작업을 밀어넣게 된다.

## 6. 되돌리는 법

    delete from game_platforms where store_external_id like 'psprices:%';
    delete from games g where not exists (select 1 from game_platforms p where p.game_id = g.id);
    drop table psprices_snapshot;
    drop table if exists _verify;
    drop table if exists _verify_cand;

psprices_snapshot 은 drizzle 스키마에 없다. 앱이 읽지 않는 외부 스냅샷이라 마이그레이션을
만들지 않았다. 스키마에 안 보인다고 없는 테이블이 아니다.
