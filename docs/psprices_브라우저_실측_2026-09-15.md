# PSprices 브라우저 실측과 벤치마킹

기준일: 2026-09-15
방법: curl(순수 HTTP), Playwright headless Chromium, Playwright 실제 Chrome 채널 세 경로를 같은 URL에 각각 때려서 비교

---

## 0. 결론 먼저

1. **크롤링은 막혀 있지 않다.** 평범한 브라우저 UA를 붙인 curl 한 방으로 한국 지역 페이지 본문이 그대로 온다. 앞서 "안 된다"고 본 403은 사이트가 막은 게 아니라 **headless 크로미움 지문**이 걸린 것이다.
2. 지역을 한국으로 두면 한국어 제목, 원화 가격, 한국 카탈로그가 전부 노출된다. 전체 할인 컬렉션은 **4,465건, 125페이지, 페이지당 36건**이다.
3. 딱 하나, **가격 이력만 난독화**돼 있다. HTTP 로는 암호 문자열만 오고, 브라우저에서는 복호된 뒤 SVG 로 그려지므로 좌표를 역산하면 복원된다.

## 1. 접근 경로별 실측

| 경로 | 순수 curl | headless 크로미움 | 실제 Chrome |
|---|---|---|---|
| `/region-kr/index` | 200, 441,654바이트 | 200 | 200 |
| `/region-kr/collection/all-discounts` | 200, 674,290바이트 | **403 Cloudflare** | 200 |
| `/region-kr/game/{id}/{slug}` | 200, 336,928바이트 | 미측정 | 200 |
| `/robots.txt` | **Cloudflare 챌린지** | 미측정 | 미측정 |

curl 에 붙인 것은 일반 Chrome UA 와 `Accept-Language: ko-KR` 뿐이다. 쿠키, 세션, 프록시 없이 통과했다.

읽어낼 점이 두 가지 있다.

- 방어는 **경로가 아니라 클라이언트 지문**을 본다. headless 크로미움만 골라 떨어뜨렸다. 우리 수집기가 이미 쓰는 `createHttpClient({ transport: "curl" })` 경로가 여기에 그대로 맞는다.
- `robots.txt` 만 챌린지가 뜬 것은 봇 판별 대상 경로라서다. 즉 **명시적 수집 정책을 확인하기 어렵게 해놨다**. 이건 뒤에서 다시 다룬다.

## 2. 데이터가 어디까지 열리나

### 2-1. 목록 페이지에서 바로 나오는 것

카드 하나가 서버 렌더 HTML 로 내려오고, 카드마다 이 값이 다 들어 있다.

- 게임 식별자(`data-game-id`)
- 할인율, 현재가, 정가, 통화 기호
- 제목, 그리고 제목 괄호 안에 **지원 언어 목록**
- PS5 Pro 지원 같은 하드웨어 배지
- 메타크리틱 점수와 오픈크리틱 점수, 각 원문 링크
- 카드 액션 4종: 알림, 좋아요, 보유, 숨기기
- 타 지역 보유 표시 오버레이

페이지네이션은 `?page=N` 단순 쿼리다. 별도 토큰이 없다.

### 2-2. 상세 페이지

구조화 데이터가 `ld+json` 으로 두 벌 박혀 있다.

- `Product`: `sku`(예 `UP1003-PPSA20560_00-DOOMTDAPREMIUMED`), `AggregateOffer` 의 `lowPrice` 와 `highPrice`
- `VideoGame`: `gamePlatform`, `price`, `priceCurrency`, 재고 상태

`lowPrice` 가 역대 최저가 역할을 한다. 파싱이 아니라 **표준 스키마를 그냥 읽으면 되는** 자리다.

### 2-3. htmx 조각 엔드포인트

상세 HTML 안에 지연 로딩용 주소가 그대로 노출돼 있다.

```
/game/fragment/chart/{game_id}/{서명토큰}
/game/fragment/addons/{game_id}/{서명토큰}
/game/fragment/partners/{game_id}
```

서명토큰은 `base64({"game_id":7933537}) + HMAC` 꼴이고 **상세 페이지 HTML 안에 들어 있다**. 상세를 한 번 받으면 토큰을 꺼내 조각을 바로 부를 수 있다. 실측으로 `addons` 는 44,948바이트짜리 에디션과 DLC 목록을 돌려줬다.

### 2-4. 유일하게 막힌 것, 가격 이력

`chart` 조각은 이렇게 온다.

```html
<script id="dynamics-data" type="application/json">"CQ4SiVFAmI2Qch2NeBjMg8VbQcBJxATQ..."</script>
```

JSON 이라고 선언해놓고 내용은 그들 자체 암호 문자열이다. HTTP 로는 여기서 끝이다.

브라우저로 열면 다르다. 복호 후 SVG 로 그려지고, DOM 에 이게 남는다.

- 선 경로: `M0,2.727L367.529,2.727L367.529,9.545L399.316,9.545...` (계단형 가격 변동)
- X축 눈금: `Apr 01, 2025` 부터 `Jul 01, 2026`
- Y축 눈금: `0.00` 부터 `120,000.00`

축 두 개가 텍스트로 있으니 좌표를 실제 날짜와 원화로 되돌릴 수 있다. **가격 이력을 원하면 브라우저가 필요하고, 나머지는 전부 HTTP 로 충분하다.**

## 3. 벤치마킹, 우리에게 없는 것만

이미 가진 것(가격 그래프, 찜, 알림, 푸시, 역대 최저가, 할인 종료일, DLC, 에디션 정리, 구독, 유저 점수, 패치 기록)은 뺐다.

### A. 목적형 컬렉션 9개

실측된 컬렉션 슬러그다.

```
all-discounts, lowest-prices-ever, free, game-pass, ps-plus-game-trials,
ps5-enhanced, xbox-play-anywhere, xbox-series-xs, avatars
```

우리는 홈과 검색뿐이다. 이게 왜 중요하냐면, 검색어를 모르는 사람의 진입구가 컬렉션이고 그 URL 하나하나가 그대로 색인 대상이 된다. 우리 데이터로 지금 당장 만들 수 있는 것은 **역대 최저가 도달**, **구독 포함**, **한국어 지원**, **출시 예정** 넷이다. 새 수집이 필요 없다.

### B. 한국어 지원 필터

제목 괄호에 언어를 박아두는 방식은 조악하지만 목적은 정확하다. 한국 사용자가 가장 먼저 거르는 축이 **한국어 자막과 음성**이다. 우리는 이 필터가 없다. 스토어별로 언어 정보를 이미 받고 있는지부터 확인할 값어치가 있다.

### C. 개인 상태를 4개로 쪼갠 것

알림, 좋아요, 보유, 숨기기를 **서로 다른 버튼**으로 둔다. 우리는 찜 하나로 뭉쳐 있다. 특히 **보유**와 **숨기기**가 없다.

- 보유: 이미 산 게임에 할인 알림을 보내는 사고를 막는다
- 숨기기: 목록 품질을 사용자가 직접 올리게 한다

둘 다 테이블 하나에 행 추가 수준이고, 알림 정확도를 바로 끌어올린다.

### D. 타 지역 보유와 지역 간 가격 비교

카드에 "다른 지역에서 이미 보유 중" 오버레이가 붙는다. 우리는 통화를 환산하지 않는 규칙을 이미 세워놨으니(`lib/currency`) 여기에 **같은 게임의 다른 지역 가격을 나란히 보여주기**만 얹으면 규칙을 깨지 않고 확장된다.

### E. 표 보기와 내보내기

카드 보기 말고 `display=table` 로 표 보기가 있고, 레딧 표 형식으로 내보내기도 있다. 가격 비교는 결국 **표가 편한 작업**이다. 우리 카드 목록에 표 전환 하나 붙이는 건 화면 하나 값이다.

### F. 필터 축

실측된 필터는 이렇다: 가격 범위(원화), 최소 할인율, 출시 연도, 평점, PC 전용, 스토어에서 내려간 항목 표시, 좋아요만 보기.

**최소 할인율**과 **스토어에서 내려간 항목 표시** 둘이 눈에 띈다. 앞엣것은 "30% 이상만"이라는 실제 구매 행동에 바로 붙고, 뒤엣것은 판매 종료를 숨기지 않고 사용자가 선택하게 만든다. 우리 `freshness` 표시와 결이 같다.

## 4. 데이터를 쓸 때의 선

기술적으로 열린다는 것과 써도 된다는 것은 다르다.

- PSprices 는 유료 B2B API 를 판다. 같은 데이터를 스크래핑으로 대체하는 것은 그들의 상품을 그대로 깎아먹는 행위다.
- `robots.txt` 를 챌린지 뒤에 둔 것은 수집을 환영하지 않는다는 신호로 읽는 게 맞다.
- 무엇보다 PSprices 가 가진 가격은 **우리가 스토어에서 직접 받을 수 있는 값**이다. 우리는 이미 Steam, PS, Xbox, 닌텐도, Epic, GOG 어댑터를 돌리고 있다. 남의 집계본을 긁어올 이유가 없다.

권고는 이렇다.

- **가격과 카탈로그는 계속 공식 스토어에서 직접 받는다.** PSprices 를 수집원으로 붙이지 않는다.
- PSprices 는 **화면 설계와 필터 축 참고용**으로만 본다. 이번 실측이 딱 그 용도다.
- 굳이 교차 검증이 필요하면 공개 B2B 데모(지역당 24건, 페이지네이션 없음)까지만 쓴다.

## 5. 바로 집을 것

새 수집 없이 지금 데이터로 되는 순서다.

1. 목적형 컬렉션 4종(역대 최저가 도달, 구독 포함, 한국어 지원, 출시 예정)
2. 보유와 숨기기 상태 추가, 보유 게임은 알림에서 제외
3. 목록 필터에 최소 할인율과 가격 범위
4. 카드와 표 보기 전환

한국어 지원 필터와 지역 간 가격 비교는 스토어별 언어와 지역 데이터가 지금 어디까지 들어와 있는지 확인한 뒤에 정한다.
