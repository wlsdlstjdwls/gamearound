## 착수 전 규칙 (여섯 번째로 확인됨)

이번에도 앞 문서의 숫자가 틀렸다. 이번엔 **우리 도구가 우리를 속인 경우**다.

**왜 111 이 나왔나.** 생 SQL 의 `\s`, `\(` 를 Neon 드라이버가 먹는다(메모: Neon 드라이버 백슬래시).
백슬래시가 죽은 정규식은 오류를 내지 않고 **아무것도 못 떼고 조용히 통과한다**. 그래서 꼬리표만
다른 묶음이 "제목이 다르다" 로 세어졌다. POSIX 문자류(`[[:space:]]`, `[(]`)로 다시 적으면 맞는다.

## 1. patch-ko 뽑기 큐 머리막힘 (커밋 aeebf33)

큐가 `title_ko is null` + 최신순이라, 뽑아 놓고 되쓰지 않은 행이 다음 회차 맨 앞에 다시 선다.
본문이 한글이라 export 가 **조용히 걸러 내던** 행은 되쓸 방법 자체가 없어 영구히 머리를 막았다.

- 거르지 않고 표시만 단다 — `bodyIsKorean`, `titleIsKorean`. 되쓰기 한 번이면 큐에서 빠진다
- `--offset` 을 안전판으로 둔다. 그래도 못 쓰는 행이 있으면 건너뛴다
- 되쓰기 끝에 남은 수를 센다. 회차 사이 진행을 재려고 DB 에 또 붙는 일을 없앤다

실측: 남은 2,572건, 제목이 이미 한글인 행 11건, steam ref 가 없어 영영 못 뽑는 행 0건.

## 2. 상품 매핑 검수 화면 (커밋 2c92b38)

`/admin/products`. 배치가 "중간"(0.7~0.9)으로 남긴 후보를 사람이 잇거나 무른다.

**거절을 기록으로 남긴다**(0036 `products.game_match_rejected_id`). 배치는 이레마다 같은 카탈로그를
다시 견주므로, 그냥 비우면 다음 회차가 같은 후보를 같은 자리에 다시 올린다 — 사람이 거절할수록
큐가 차는 쳇바퀴다. 물린 후보를 남기면 배치가 그 하나를 건너뛰고 **그다음 후보**를 본다.

잇는 일은 배치와 같은 함수(`linkProductToGame`)가 한다. 두 벌로 두면 한쪽만 구성품을 남기는 날이
오고, 증상이 "이었다는데 게임 화면에 안 뜬다" 라 원인을 찾기 어렵다.

0036 에 `product_components_game_uq`(부분 unique)도 같이 넣었다 — 같은 상품에 같은 게임이 두 줄이면
"파는 곳" 에 같은 매장이 두 번 뜬다. 넣으려는 경로가 셋(매장 등록, 배치, 검수)이라 DB 가 막는다.

끝단 실측(로컬 4000, 표본은 끝에서 지웠다): 화면 표시, 잇기(구성품 1줄까지), 무르기, 처리 후 큐에서
빠짐, 배치가 물린 후보를 건너뜀 — 전부 통과.

**Server Action 을 대본으로 부르는 법**(다음에 또 필요하다): dev 번들에는 액션 id 가 정적으로 안 보인다.
`.next/dev/server/server-reference-manifest.json` 의 `node` 에서 그 화면을 `workers` 에 가진 id 를
집으면 된다. 이름은 안 적혀 있어 어느 것이 무엇인지는 불러 보고 DB 로 가린다.
**그중 하나는 로그아웃이다** — 부르면 세션이 끊겨 뒤의 시도가 전부 "로그인이 필요합니다" 가 된다.

## 3. xbox 중복 접기 (커밋 d451f50)

`pnpm dedup:stores [--source xbox] [--limit N] [--apply]`. 기본은 미리보기.

**무엇만 접었나.** 기종 꼬리표(`(Xbox One)`, `— Windows`)만 다르고 나머지 이름이 같은 **본편** 묶음.
xbox 가 스토어 ID 하나를 세 행으로 쪼개 만든, 우리가 만든 중복이다.

**왜 지우지 않고 옮기나.** 86묶음 **전부**가 가격 이력을 두 행 이상에 나눠 갖고 있었다. 순서가 중요하다:
자식(`parent_game_id`)을 먼저 옮기고 → 같은 (플랫폼, 지역) 행은 이력만 옮겨 합치고 → 빈 칸만 메우고
→ 마지막에 껍데기를 지운다. 충돌하는 부속 행은 옮기지 않고 껍데기와 함께 사라지게 둔다.

| | 접기 전 | 접은 뒤 |
|---|---|---|
| games | 57,908 | 57,794 |
| 본편 | 14,728 | 14,614 |
| DLC | 35,414 | **35,414** |
| 가격 스냅샷 | 21,002 | **21,002** |
| 패치 기록 | 3,660 | **3,660** |
| 중복 묶음(외부 ID 축) | 218 | 128 |

살아남은 86행에 같은 스토어 ID 중복 0, 같은 (플랫폼, 지역) 행 중복 0, 꼬리표 잔재 0(제목과 주소 둘 다).
되돌리기: `dupmerge_games_20260918`, `dupmerge_platforms_20260918`, `dupmerge_map_20260918`.

**0037 — `games.parent_game_id` 를 cascade 에서 set null 로.** 부모를 지우면 자식 DLC 가 소리 없이
따라 죽던 자리다. 부모 없는 DLC 는 목록에 안 뜰 뿐 되살릴 수 있지만, 지워진 행은 되돌릴 데가 없다.

행당 6.2초였다(왕복이 많다). 86묶음에 12분쯤.
