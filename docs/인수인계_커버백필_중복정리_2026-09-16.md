# 인수인계 — 커버 백필, 중복 정리, DLC 판정 (2026-09-16)

psprices 병합이 남긴 빚 세 가지를 갚은 회차다. 시작은 "게임 이미지가 안 나온다" 는 한 줄이었고,
파 보니 커버 결손, 중복 행, 분류 오류가 한 뿌리에서 나왔다.

## 1. 커버가 안 나오던 진짜 이유

화면 코드는 멀쩡했다. `FadeImage`, `ImageFallback` 는 실패 처리까지 제대로 하고 있었다.
문제는 **채울 값이 없었다**는 것이다.

- `games` 73,284건 중 `cover_url` 없음 **62,927건(86%)**
- 그중 62,556건은 `game_source_refs` 자체가 없다 — 전부 psprices 병합분
  (`game_platforms.store_external_id` 가 `psprices:<id>`, `store_url` 도 psprices.com)
- 진짜 스토어 ID 가 없으니 기존 어댑터가 이 행들을 **영영** 못 채운다

커버를 얻는 유일한 경로는 psprices **상세 페이지의 JSON-LD `Product.image`** 였다.
목록 덤프(`artifacts/psprices_kr_all.jsonl`, `_deep.jsonl`)에는 이미지 필드가 없다.

### 주의: 기존 `_tmp-psprices-detail.py` 의 cover_url 은 틀렸다

HTML 의 첫 이미지를 집는 방식이라 Xbox 게임에 PlayStation CDN 주소가 붙거나
opencritic 잡지 사진이 붙었다. **그 파일의 cover_url 을 믿지 말 것.** JSON-LD 를 쓴다.

### 핫링크 실측 (리퍼러 gamearound.kr)

| 호스트 | 응답 |
|---|---|
| `c.psprices.com` | **403** |
| `image.api.playstation.com` | 200 |
| `store-images.s-microsoft.com` | 200 |
| `store.nintendo.co.kr` | 200 |

psprices 자기 CDN 주소는 **저장하면 안 된다**. 저장하는 순간 화면에서 전부 깨진다 — 비어 있는 것보다 나쁘다.
응답의 약 24%가 이 경우였고 전부 버렸다. 대신 SKU 를 같이 적어 뒀다(아래 3번이 그걸 썼다).

### 결과

- 38,425건 처리, 커버 38,420건 확보 (실패 1, 일시 오류 4)
- DB 반영 **28,730건**, psprices CDN 이라 버린 것 9,690건
- 커버 보유율 전체 14%에서 **68.9%** 로, 본편은 **76.9%**
- 일꾼 4, 간격 0.7초로 약 3시간

## 2. 중복 — 껍데기 행 14,675개

검색에서 "호그와트 레거시" 가 14줄로 흩어져 나오던 원인이다.
병합 때 슬러그가 부딪히자 숫자 접미사를 붙여 새 행을 만들었는데, 가격과 스토어 연결은
먼저 있던 행에 붙어서 이쪽은 제목만 남았다.

전수 확인 결과 이 행들이 든 것: `game_source_refs` 0, `wishlists` 0, `price_alerts` 0,
`game_genres` 0, 자식 DLC 0, `cover_url` 0, `description` 0. 같은 제목의 실물이 없는 외톨이도 **0건**.
지워도 사라지는 게임이 없다는 뜻이다.

**지운 뒤 본편 같은제목 중복 묶음 10,303 에서 0.** 백업은 `artifacts/shell_rows_backup.jsonl`.

## 3. 변형과 DLC 를 본편 자리에서 내리기

목록은 `filters.mainGamesOnly()` 로 본편만 본다. 변형과 DLC 를 내리면 목록에서 빠지고 본편 상세에 묶인다.

### 3-1. 기종 변형, 에디션 1,146건

제목이 "부모 제목 + 변형 꼬리" 꼴인 것을 정규화 접두 일치로 찾았다.

**여기서 배운 것 — 다음에 같은 일 할 때 그대로 적용할 것**

- **부모가 실제로 있을 때만 내린다.** 꼬리 규칙만 보고 전부 내리면 안 된다. 실측 82건 중 69건은
  부모가 카탈로그에 없었다(GOG 이 GOTY 에디션만 파는 식). 내리는 순간 그 게임이 화면에서 통째로 사라진다.
- **리마스터는 변형이 아니다.** 값도 평도 따로 붙는 별개 상품이라 본편 자리를 준다(20건 제외).
- 부모 색인에 **`title_ko_norm` 도** 넣어야 한다. 변형 제목이 한글이면 영문 색인만으로는 못 찾는다
  ("호그와트 레거시 Xbox One 버전" 의 부모는 `title_en` 이 "Hogwarts Legacy" 다).
- 부모가 또 변형이면 **뿌리까지** 거슬러 붙인다. 상세는 손자를 보여주지 않아서 사슬로 두면
  중간 것이 어디에도 안 보인다.

### 3-2. DLC 판정 — 제목이 아니라 스토어가 매긴 값으로

| 스토어 | 신호 | 내린 건수 |
|---|---|---|
| PlayStation | SKU 세 번째 칸. 본편은 네 글자 뒤에 0 이 열두 개, 애드온은 그 자리에 자기 식별자 | 약 20,700 |
| Xbox | displaycatalog 의 `ProductKind` 가 `Durable` | 8,170 |

PlayStation 예시는 본편이 `KP0004-CUSA03038_00-GAME000000000000`,
애드온이 `EP4008-CUSA10564_00-W40KIM0EDSPDLC16` 이다. 언어와 표기를 타지 않는다.

Xbox 는 규칙을 새로 쓰지 않고 `xboxAdapter.fetchMany` 를 그대로 불렀다 — `xbox.ts` 의
`XBOX_ADDON_KIND` 가 이미 그 판정을 한다. 배치 20, 요청 약 1,658회, 실패 배치 0.

### 결과

`game` 44,537에서 **15,752** | `dlc` 6,182에서 **35,455** | `edition` 4,668 | `bundle` 2,514 | `demo` 715

## 4. 화면 변경

상세의 자식 칸이 유형과 무관하게 전부 "DLC" 라는 이름으로 그려지고 있었다.
에디션을 그대로 붙이면 에디션이 DLC 로 읽힌다. `GameDetailDto.editions` 를 새로 두고
**"에디션, 기종별 판"** 칸을 나눴다. 줄 모양은 `DlcList` 를 함께 쓴다 — 묻는 것이 "제목과 값" 으로 같고,
모양이 다르면 같은 화면에서 두 번 배워야 한다.

건드린 파일: `dto.ts`, `detail.ts`(`toChildDtos`), `mappers.ts`, `lib/games/messages.ts`, 상세 `page.tsx`

## 5. 남은 일

1. **DLC 에 부모 잇기.** 지금은 부모 없는 DLC 라 목록에서 빠지고 검색으로만 닿는다.
   PS SKU 안에 타이틀ID(CUSA/PPSA)가 있지만 우리 psstore 행은 콘셉트 번호(`10006164`)를 들고 있어
   짝이 안 맞는다(실측 애드온 6,202건 중 311건만 매칭). psstore 어댑터로 타이틀ID 를 다시 맞출 때 함께 한다.
   정리 전에도 dlc 6,182건 중 1,620건이 부모 없음이었다 — 새로 생긴 상태가 아니다.
2. **버린 9,690건의 커버.** psprices CDN 이라 버렸지만 SKU 는 `artifacts/psprices_cover.jsonl` 에 있다.
   Xbox/PS 어댑터로 원 스토어에서 받으면 된다.
3. **커버 없는 나머지.** 본편 15,752건 중 3,646건이 아직 비어 있다.

## 6. 함정 기록

`pnpm build` 가 `globals.css` PostCSS 단계에서 `0xc0000142` 로 죽는 일이 있었다.
프로세스 경합처럼 보이지만 아니다 — 크롤러가 다 내려간 뒤에도 똑같이 실패했다.
**Turbopack 캐시 손상**이고 `.next/cache` 를 지우면 한 번에 통과한다.
