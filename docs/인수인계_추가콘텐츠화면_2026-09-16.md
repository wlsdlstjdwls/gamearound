# 인수인계 — 추가 콘텐츠 화면 (2026-09-16)

게임 상세의 DLC, 에디션 칸을 세 번에 나눠 고친 회차다. 세 가지 다 같은 불만에서 나왔다 —
**자식(DLC, 에디션)을 본편과 구분해 주지 않아 화면이 거짓말을 하고 있었다.**

커밋 `1cd7de3`, `6d4c49f`, `76107bf`. main 에 푸시됐다.

## 1. 플랫폼별로 안 보여 남의 기기 값을 읽고 있었다 (`1cd7de3`)

행마다 `cheapestPlatform()` 하나만 찍었다. 그런데 실측하면:

| | |
|---|---|
| 자식 게임 | 15,560건 |
| 본편과 플랫폼 집합이 **다른** 자식 | 10,648건 (68%) |
| 2개 이상 플랫폼에 걸친 DLC | 6,648건 |

몬헌 라이즈 `Deluxe Kit` 은 `steam=9,400 / xbox=7,400` 인데 화면엔 "7,400 Xbox" 만 떴다.
PS 유저는 그게 자기 기기에 있는지조차 몰랐고, 스팀에 없는 DLC 도 그 사실이 안 보였다.

`DlcList` 를 `DlcSection` 으로 바꾸고 플랫폼 칩을 달았다. 고르면 목록도 값도 그 플랫폼 것이 된다.
**머리(건수)까지 컴포넌트 안으로 들였다** — 필터를 걸었는데 머리가 전체 건수를 말하면 어느 쪽이 참인지 알 수 없다.

주의: 이 컴포넌트는 `"use client"` 다. 값 계산에 `@/server/services/games` 를 **값으로** 들여오면
클라이언트 번들에 DB 클라이언트가 딸려 온다(진입점이 detail, list 를 함께 내보낸다). `lib/currency` 의 `cheapestOf` 를 직접 쓴다.

## 2. 자식 상세가 본편과 똑같이 생겼다 (`6d4c49f`)

DLC 도 `games` 행이라 자기 상세를 갖는다. 그래서 DLC 화면만 보면 "왜 이 게임은 2,400원이지",
"왜 플레이타임이 없지" 로 읽혔고, 본편으로 돌아갈 길도 "게임 목록으로" 하나뿐이었다.

- `GameDetail` 에 `contentType`, `parent` 신설. 공개 API(`/api/v1/games/[slug]`)도 같이 싣는다.
- `components/content-kind-head.tsx` — 종류 배지 + 본편 버튼. 버튼에 본편 제목을 그대로 적는다.
- 부모를 모르는 자식이 18,642건이라 `parent` 는 null 이 흔하다. 그때는 배지만 세운다.

## 3. 30줄이 꾸미기로 차서 확장팩이 안 보였다 (`76107bf`)

DLC 로 묶인 34,243건 안을 제목으로 훑으면(겹침 있음):

| 갈래 | 건수 |
|---|---|
| 코스튬, 외형 | 4,895 |
| 시즌패스, 확장팩 | 721 |
| 사운드트랙 | 580 |
| 캐릭터, 챕터 | 476 |
| 재화, 소모품 | 208 |
| 아트북, 부록 | 49 |

사운드트랙을 "DLC" 라 부르는 것도 틀렸지만, 더 아픈 건 목록이었다. 몬헌 라이즈는 자식이 504건인데
상세 30줄이 전부 "덧입는 장비" 로 찼고 확장팩 SUNBREAK 은 안 보였다.

- **어휘**: 섹션 제목과 배지를 "DLC" 에서 "추가 콘텐츠" 로. 셋 다 참인 말은 이것뿐이다.
- **정렬**: `lib/games/addon-kind.ts` 가 제목으로 갈래를 추정하고 **갈래, 값, 제목** 순으로 세운다.
- **읽는 폭**: 자식 300건을 읽어 세운 뒤 30건으로 자른다. 전에는 질의가 아무 순서 없이 앞의 30건을 잘라서,
  목록에 들지도 못한 확장팩이 있었다.

### 이 회차에서 두 번 틀렸다

**제목만으로는 확장팩을 못 올린다.** "MONSTER HUNTER RISE: SUNBREAK" 어디에도 확장팩이라는 말이 없어
unknown 으로 떨어지고, 제목순에 밀려 "【헌터 특전】엘가도 이득 패키지(무료)" 아래로 내려갔다.
**값을 두 번째 열쇠로** 넣어 풀었다 — 값은 스토어가 직접 매긴 무게다(확장팩 6,720원, 덧입는 장비 1,900원, 특전 0원).

**정렬 기준을 바꿀 때도 `DTO_CACHE_VERSION` 을 올려야 한다.** 필드가 아니라 순서만 바뀐 경우라
화면은 멀쩡히 뜨면서 옛 순서를 그대로 냈다. `lib/cache.ts` 주석이 경고하던 바로 그 경우인데 또 밟았다(v7 → v8).

### 갈래를 배지로 적지 않는 이유

제목 규칙은 다국어 카탈로그에서 반드시 구멍이 난다. 배지로 적으면 틀린 사실이 화면에 박히지만,
정렬로만 쓰면 오탐의 대가가 "순서가 조금 어긋난다" 로 끝난다. 규칙을 늘릴 때는 **그 낱말이 들어간 실제 제목**을
테스트에 같이 남긴다. 다 잡으려 들지 않는다 — 상위 몇 줄이 확장팩으로 서면 목적은 이룬 것이다.

## 다음에 할 일

### A. 스토어가 주는 진짜 종류를 싣는다

`games.addon_kind` 를 신설하면 추정을 배지로 승격할 수 있다. 신호는 이미 다 들어오고 있다:

| 스토어 | 신호 | 지금 상태 |
|---|---|---|
| Steam | `appdetails.type` 에 `music` | `adapters/steam/parse-app-details.ts` 가 `dlc` 만 보고 버린다 |
| Xbox | `ProductKind` 의 `Durable`(콘텐츠) / `Consumable`(재화) | `adapters/xbox.ts` 가 Durable 만 본다 — **재화가 본편으로 샌다** |
| PlayStation | `storeDisplayClassification` | 이미 읽는다(`PSSTORE_NON_DLC_CLASSIFICATIONS`). 화폐는 수집 단계에서 버린다 |

Xbox 누수는 카탈로그 오염이라 배지와 별개로 고칠 값어치가 있다.

### B. "30개" 가 전부가 아니다

섹션 머리의 건수와 플랫폼 칩 구성이 **화면에 온 30건 기준**이다. 자식이 수백 개인 게임에서
"Xbox 3개" 는 전부가 아니다. 칩을 주소 쿼리로 올려 서버에서 거르거나, 목록에 "더 보기" 를 붙인다.
